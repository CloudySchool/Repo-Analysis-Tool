### COMS3011A RAT Test
- Definition：The Columbia University course assessment (RAT = Restricted Assessment Test) that this project is built around; it requires implementing a git repository analytics dashboard with five metric categories (file, directory, repository, commit-set, author), supporting zip and URL ingestion, filtering, author merging, and multi-repo views.
- Aliases：COMS3011A、RAT
