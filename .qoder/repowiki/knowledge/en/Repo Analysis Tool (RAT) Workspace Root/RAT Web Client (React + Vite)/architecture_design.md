Vite-powered React SPA rooted at `index.html`, bootstrapped by `src/main.jsx` which mounts `<App />` into `#root`. `App.jsx` is the top-level component managing global state (repos, jobs, toasts, current view) and routing between a 'repos' list/add view and a 'dash' view rendered by `Dashboard.jsx`. All HTTP calls are centralized in `src/api.js`, which exposes a single `api` object wrapping `fetch` against `/api` endpoints; a local `j()` helper normalizes error responses. Chart rendering lives in `charts.jsx` (ECharts), formatting helpers (`fmt`, `timeAgo`) in `format.js`, and all styling is in `styles.css`. The Vite dev server proxies `/api` to `http://localhost:4000`, decoupling the frontend from the backend during development.
